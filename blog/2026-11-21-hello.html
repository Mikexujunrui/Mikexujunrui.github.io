你好，世界：为什么我给自己搭了一个个人主页

2026-11-21 · 徐俊瑞 (Junrui Xu) · 约 3 分钟

这个站点的第一篇文章，理应回答一个问题：都 2026 年了，为什么还要手写一个静态个人主页？

为什么要有这个主页

过去一年多，我的身份在几个角色之间来回切换：国家同步辐射实验室的研究生、材料计算智能体 MatCreator 的开发者、AI 小说创作智能体 AnySpark 的独立作者， 还有 AI4MS 固态电池新材料探索的创业参与者。这些碎片散落在简历、聊天记录和各个仓库的 README 里，没有一个地方能把它们完整地拼起来。

于是有了这个页面：一个纯 HTML + CSS 的静态站，托管在 GitHub Pages 上，没有框架、没有构建步骤、没有数据库。 打开 index.html 就能看到全部。这种"土法"恰恰是我想要的——它足够简单，简单的东西才维护得动。

这里会写什么

大概三类内容：

一是 Agent 实践。我现在的核心判断是：现有 Agent 体系强烈依赖人类充当"人肉总线"和"人肉端口"， 基于 session 的管理范式占用了人类有限的注意力窗口。我感兴趣的是跨会话、跨任务、跨设备、跨组织的个人 Agent 该如何工作——Open Agent World 的知识库模块和 AnySpark 的画布工作流，都是这个判断的实验品，踩过的坑会记在这里。

二是 AI for Science 与大科学装置。同步辐射光源这类大科学装置的智能化改造和 AI 自动化实验， 是我研究生阶段的主线课题。这个领域的论文和工程实践之间隔着一道很宽的沟，我希望把沟两边的东西都记一点。

三是日常思考。关于科研、工具、读书，或者单纯觉得有意思的东西。

一个原则

写下来的东西要对未来的自己有用，而不是对当下的情绪有用。

所以更新频率可能不高，但每一篇都尽量带着具体的上下文：做了什么、为什么这么做、哪里做错了。

如果你对 Agent、AI for Science 或者任何奇怪的话题感兴趣，欢迎通过 邮件 或者 GitHub 找到我。
